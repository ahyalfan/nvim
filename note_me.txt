### 1. **Menghapus Per Kata**

Untuk menghapus teks satu kata dalam Vim, kamu bisa menggunakan perintah berikut:

- **`dw`** - Menghapus satu kata dari posisi kursor hingga akhir kata.
  - Contoh: Jika kursor berada di tengah kata "Hello", maka perintah ini akan menghapus "Hello".
  
- **`daw`** - Menghapus seluruh kata, termasuk spasi sebelum atau setelah kata.
  - Contoh: Jika kursor berada di tengah "Hello world", perintah ini akan menghapus "Hello" beserta spasi setelahnya.

- **`de`** - Menghapus dari posisi kursor hingga akhir kata (tanpa menghapus spasi setelahnya).
  - Contoh: Jika kursor berada di tengah kata "Hello world", perintah ini akan menghapus "Hello" tetapi mempertahankan spasi setelahnya.

### 2. **Menghapus Per Kalimat**
Untuk menghapus seluruh kalimat, kamu bisa menggunakan perintah berikut:

- **`d.`** - Menghapus satu kalimat dari posisi kursor.
  - Contoh: Jika kursor berada di tengah kalimat "This is a test.", perintah ini akan menghapus "This is a test.".

- **`d2.`** - Menghapus dua kalimat berturut-turut mulai dari posisi kursor.
  - Contoh: Jika kursor berada di tengah kalimat pertama, perintah ini akan menghapus dua kalimat berturut-turut.

- **`di"`** - Menghapus isi dalam tanda kutip (menggunakan tanda kutip ganda).
  - Contoh: Jika kursor berada di dalam tanda kutip `"hello world"`, perintah ini akan menghapus teks di dalam tanda kutip tersebut.

- **`di'`** - Menghapus isi dalam tanda kutip tunggal.
  - Contoh: Jika kursor berada di dalam tanda kutip `'hello world'`, perintah ini akan menghapus teks di dalam tanda kutip tersebut.

### 3. **Menghapus Seluruh Baris**
Jika kamu ingin menghapus satu baris penuh:

- **`dd`** - Menghapus seluruh baris tempat kursor berada.

### 4. **Menghapus Hingga Karakter Tertentu**
Kamu juga bisa menghapus teks hingga karakter tertentu dalam satu baris:

- **`dF<char>`** - Menghapus hingga karakter `<char>` dari posisi kursor (termasuk karakter itu sendiri).
  - Contoh: Jika kursor berada di "Hello, world!" dan kamu mengetik `dF,`, maka teks yang terhapus adalah "Hello,".

- **`dT<char>`** - Menghapus hingga sebelum karakter `<char>`.
  - Contoh: Jika kursor berada di "Hello, world!" dan kamu mengetik `dT,`, maka teks yang terhapus adalah "Hello".

### Ringkasan:
- **`dw`** - Hapus satu kata.
- **`daw`** - Hapus seluruh kata.
- **`d.`** - Hapus satu kalimat.
- **`dd`** - Hapus satu baris.
- **`dF<char>`** - Hapus hingga karakter tertentu, termasuk karakter itu sendiri.
- **`dT<char>`** - Hapus hingga sebelum karakter tertentu.

-- Default shortcuts
Ctrl+h        select file tree
Ctrl+l        select file editor
Shift+h       left editor tab
Shift+l       right editor tab
Alt+j         move current line up
Alt+k         move current line down
double space  filename search(telescope) - `Ctrl+d` and `Ctrl+u` to scroll preview
gg=G          reindent - gg goes to the top of the file, = fixes the indentation and G to perform to the end
gc            comment selected(`gcgc` no select to uncomment block)
%             jump to other bracket of the current block
_             jump to the first non blank char on the line
$             jump to the last non blank char on the line
0             jump to the start of the line
\text         seach for text, `n` for next occurence, `N` for previous
f"            find first `"`, jump to it with right arrow
ci"           delete and start editing inside of the next string literal
vi"           select inside of the next string literal
viw           select current word
di"           delete inside of the next string literal
u             undo
Ctrl+r        redo
ma            set local mark `a`
mA            set global mark `A`
`             list marks
`a            go to mark `a`

-- No tree
r           rename
m           move
o           order by
i           file details
v           available shortcuts 
Ctrl+rarrow  expand tree to right
Shift+h     Toggle show hidden files

-- Visual mode 
Character mode - `v`
Line mode - `V`
Block mode - `Ctrl+v`
`u`- lowercase
`U`- uppercase
`d`- delete
`c`- change
`y`- yank
`>`- indent
`<`- dedent

-- insert mode 
<esc>           Leave INSERT mode
<del>           Delete left
<fn><del>       Delete right
<ctrl>w         Delete word before cursor
<ctrl>u         Delete left until the end of line
